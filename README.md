# FlowStatic AI

A modern SaaS landing page built with React, Vite and Tailwind CSS.

## Features

* Responsive Design
* Dark Mode
* Smooth Navigation
* Interactive FAQ
* Pricing Section
* Modern SaaS UI

## Tech Stack

* React
* Vite
* Tailwind CSS
* JavaScript

## Live Demo

https://flowstaticai-referencework.netlify.app/

## Purpose

This project was created as a portfolio and learning project focused on modern frontend development, responsive design, and component-based architecture.
